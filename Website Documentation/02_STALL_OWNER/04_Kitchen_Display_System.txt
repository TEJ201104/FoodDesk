1. FEATURE OVERVIEW
--------------------------------------------------------------------------------
The Kitchen Display System (KDS) (/kds) is a high-visibility, real-time 4-column digital Kanban station designed for food preparation staff, line cooks, and kitchen expediters.

It completely replaces physical kitchen paper order chits, rotary ticket wheels, and shouted orders across noisy food courts. Positioned on kitchen-mounted touchscreen displays, wall-mounted TVs, or counter tablets, the KDS organizes active orders into clear, sequential stages:
1. Column 1 — Received: New incoming orders just entered by the cashier at the POS.
2. Column 2 — Preparing: Orders currently on the grill, wok, fryer, or assembly line.
3. Column 3 — Ready for Pickup: Assembled, plated, or bagged orders awaiting customer pickup.
4. Column 4 — Completed: Orders handed over to customers and successfully served.

Key capabilities include:
- Ultra-prominent 3-digit pickup tokens (e.g., Token #101) readable from across the kitchen.
- Dynamic 1-second live elapsed timers showing exact wait times in minutes and seconds (e.g., "4m 12s ago").
- Automatic delay color-coding warning chefs of tickets approaching service thresholds (Green < 5 min, Yellow 5-10 min, Red > 10 min).
- One-click stage progression buttons allowing chefs to advance an order with a single touch.
- Synthesized audio bell alerts (using Web Audio API) that chime automatically whenever a new order arrives.
- Fullscreen display toggle for dedicated kitchen smart monitors and TVs.


2. HOW TO ACCESS
--------------------------------------------------------------------------------
- Direct URL: http://localhost:5173/kds
- Sidebar Navigation: Click "Kitchen Display (KDS)" (the fourth item with the ChefHat icon).
- Top Bar / Workstation Shortcuts: Click the "Kitchen KDS" button on the Dashboard or Order Management Hub.


3. SCREEN LAYOUT
--------------------------------------------------------------------------------
The KDS screen uses a high-contrast dark theme (bg-navy-950) optimized for hot, bright commercial kitchen environments:

1. Top KDS Control Bar:
   A full-width control bar displaying the chef hat emblem, active stall name, category, live queue count (e.g., "3 In Queue"), live search input, audio alert toggle ("Sound ON" vs "Muted"), native fullscreen toggle, manual refresh button, and quick jump link to POS Counter.

2. Global Empty State (Conditional):
   If there are zero active and completed orders for the current day, a celebratory "Kitchen Ready & Station Clear" card is shown.

3. Four-Column Kanban Board Layout:
   A responsive grid (1 column on mobile, 2 columns on tablet, 4 columns on large screens) representing the four preparation stages:
   - Column 1: Received (New counter tickets).
   - Column 2: Preparing (Cooking & assembling).
   - Column 3: Ready for Pickup (Call customer token).
   - Column 4: Completed (Handed over & served).


4. DETAILED ELEMENT-BY-ELEMENT EXPLANATION
--------------------------------------------------------------------------------
Every component of the KDS interface is detailed below:

A. KDS CONTROL BAR:
- Active Stall & Live Queue Pill:
  - Header: ChefHat icon in orange box + "Kitchen Display System" with green "LIVE" badge.
  - Subtitle: Store icon + Stall Name (e.g., "Fast Food Stall") + Category + Orange font-mono badge showing "[X] In Queue".
- Search Input:
  - Location: Right section of control bar.
  - Placeholder: "Search token #, order, item...".
  - Behavior: Filters cards across all four columns simultaneously.
- Audio Alerts Toggle Button:
  - Icon: Volume2 (enabled) or VolumeX (muted).
  - Label: "Sound ON" (in brand orange) or "Muted" (in slate gray).
  - Behavior: Toggles Web Audio API alerts when new orders arrive or are advanced.
- Fullscreen Toggle Button:
  - Icon: Maximize2 (enter) or Minimize2 (exit).
  - Action: Invokes document.documentElement.requestFullscreen() to fill the entire monitor.
- Refresh Button:
  - Icon: RefreshCw.
  - Action: Manually re-queries storage for orders.
- "POS Counter" Shortcut:
  - Button with ShoppingBag icon linking directly to /pos.

B. KDS COLUMN STRUCTURE (KDSColumn.jsx):
Each of the four columns features:
- Column Header:
  - Stage Title (e.g., "Preparing").
  - Stage Subtitle (e.g., "Cooking & assembling").
  - Ticket Counter Pill: Shows number of cards currently in this column (e.g., "2").
  - Stage Accent Bar: Color-coded line at the top of the column (Blue for Received, Amber for Preparing, Green for Ready, Slate for Completed).
- Scrollable Cards Container:
  - Vertical list of order cards arranged in FIFO order (First In, First Out).
- Column Empty State:
  - If a column has 0 orders, displays a dashed card reading "No orders in this stage".

C. KDS ORDER TICKET CARDS (KDSOrderCard.jsx):
Every card in a column represents one active order ticket:
1. Card Header:
   - Giant Pickup Token: Prominent 3-digit number (e.g., "#102") in 24px bold font-mono.
   - Elapsed Timer Pill:
     - Shows dynamic live elapsed time updated every second (e.g., "3m 45s ago").
     - Delay Color Coding:
       - Green: Fresh ticket (< 5 minutes elapsed).
       - Amber/Yellow: Warning ticket (5 to 10 minutes elapsed).
       - Red: Overdue / Delayed ticket (> 10 minutes elapsed).
2. Order Number & Timestamp:
   - Displays canonical Order Number (e.g., ORD-20261116-0002) and placement time (e.g., "01:22 PM").
3. Special Customer Notes Banner:
   - If the customer provided special instructions (e.g., "Extra spicy, no mayo"), a high-visibility amber callout box is rendered with an alert icon to ensure cooks do not miss customization requests.
4. Food Line Items Breakdown:
   - Itemized list formatted for quick reading:
     - Quantity Badge: High-contrast orange pill (e.g., "2x").
     - Item Name: Bold white text.
     - Dietary Indicator: Small veg/non-veg dot.
5. Customer Phone (if recorded):
   - Small font-mono phone number.
6. Stage Progression Action Button:
   - Positioned at the bottom of the card:
     - In Received column: "Start Preparing" (Amber button with Flame icon). Moves ticket to Preparing.
     - In Preparing column: "Mark as Ready" (Green button with BellRing icon). Moves ticket to Ready.
     - In Ready column: "Complete & Serve" (Dark Navy button with CheckCircle2 icon). Moves ticket to Completed.
     - In Completed column: Displays checkmark with option to revert if clicked by mistake.


5. AVAILABLE ACTIONS
--------------------------------------------------------------------------------
1. Advance Ticket to "Preparing": Touch "Start Preparing" when starting to cook the order.
2. Advance Ticket to "Ready": Touch "Mark as Ready" when the food is plated and ready for the customer.
3. Advance Ticket to "Completed": Touch "Complete & Serve" when handing the order over to the customer.
4. Search Tickets: Type a token number (e.g., "102") in the search box to find a ticket instantly.
5. Toggle Sound: Click the speaker button to turn audio alerts on or off.
6. Enter Fullscreen Mode: Click the fullscreen button to expand the display to 100% of the screen.
7. Revert Accidental Clicks: Completed or ready tickets can be moved back if tapped accidentally.


6. STEP-BY-STEP USAGE GUIDE
--------------------------------------------------------------------------------
SCENARIO: KITCHEN WORKFLOW FOR AN INCOMING ORDER
1. The cashier enters an order at the front counter POS (Token #103: 2x Burger, 1x Fries).
2. IMMEDIATELY IN THE KITCHEN:
   - A resonant kitchen bell chime rings through the speakers.
   - A blue toast notification appears: "🔔 New Order Received: Token #103 (ORD-20261116-0003)".
   - Token #103 appears at the top of Column 1 ("Received").
3. COOKING COMMENCES:
   - The chef reads the items: "2x Burger, 1x Fries".
   - The chef taps the orange "Start Preparing" button on card #103.
   - The card slides smoothly into Column 2 ("Preparing").
4. FOOD IS READY:
   - When the burgers and fries are boxed, the chef taps the green "Mark as Ready" button.
   - A completion bell chime plays.
   - Card #103 moves into Column 3 ("Ready for Pickup").
   - (Simultaneously, the customer tracking screen updates to "Ready for Pickup").
5. HANDOVER TO CUSTOMER:
   - Counter staff call out: "Token 103!".
   - Customer shows their token slip. Staff hand over the food.
   - Staff tap "Complete & Serve" on card #103.
   - Card #103 moves to Column 4 ("Completed"). The active kitchen queue is cleared!


7. SYSTEM BEHAVIOUR
--------------------------------------------------------------------------------
- Live 1-Second Clock Tick:
  The KDS runs an internal 1000ms setInterval timer that updates Date.now() every second. This guarantees that elapsed wait times ("1m 12s", "1m 13s", etc.) increment continuously in real time without screen flickers.
- Stage Progression Handler (handleTransition):
  1. Calls stallDataService.updateOrderStatus(stallId, orderId, nextStatus).
  2. Updates order.orderStatus in localStorage.
  3. Dispatches custom DOM event: window.dispatchEvent(new CustomEvent('fooddesk:order-status-updated', { detail: updatedOrder })).
  4. Triggers corresponding sound feedback:
     - Move to Ready: sound.playKitchenBell() (two-tone 800Hz / 1000Hz chime).
     - Move to Completed: sound.playSuccess() (harmonic arpeggio).
     - Move to Preparing: sound.playItemAdd() (1200Hz tick).
- Cross-Tab Synchronization:
  Any other open tabs (POS, Order History, Customer Tracker) receive the update instantly.

10. RESTRICTIONS AND IMPORTANT NOTES
--------------------------------------------------------------------------------
- Cross-Stall Separation:
  Fast Food KDS displays only Fast Food orders (stall-1). Beverage and Dessert orders will never appear on the Fast Food KDS screen.
- Web Browser Fullscreen Policy:
  Modern browsers require user interaction to enter fullscreen. Clicking the Fullscreen toggle fulfills this browser requirement cleanly.
- Super Admin Access:
  Super Admins attempting to visit /kds see an administrative compliance notice explaining that food preparation is reserved for stall kitchen staff.


11. FREQUENTLY ASKED QUESTIONS (FAQ)
--------------------------------------------------------------------------------
Q1: Can we run the KDS on a kitchen Android tablet or smart TV?
A1: Yes! Simply open the browser on the tablet or smart TV, navigate to the KDS URL, and tap the Fullscreen button. The interface automatically scales to fit any resolution.

Q2: Why did an order timer turn red?
A2: The elapsed timer turns red when an order has been waiting for more than 10 minutes without being marked as Ready. This provides an immediate visual alert to expedite delayed orders.

Q3: Can we mute the bell sounds during busy hours?
A3: Yes. Click the "Sound ON" button in the top bar to toggle it to "Muted". The visual cards will continue updating silently.
